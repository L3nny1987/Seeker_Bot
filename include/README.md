# Projektweite Header

Die aktuellen Anwendungsschnittstellen liegen neben ihren Implementierungen in `src/`. Hardwarekomponenten besitzen eigene `include/`-Verzeichnisse. Die zentrale Pinbelegung liegt in `components/seeker_config/include/seeker_pins.h`.

Dieses Verzeichnis bleibt für zusätzliche ausdrücklich projektweite Header verfügbar.
