## Markdown zu PDF

`PROJEKTBUCH.md` verwendet gewöhnliches Markdown und lokale PNG-Dateien. Beim Kopieren den Ordner `assets/` mitnehmen und relative Pfade erhalten. SVG-Originale stehen für spätere Vektorlayouts bereit. Eine optionale [Druckgestaltung](assets/print.css) kann in Konvertern eingebunden werden, die eigenes CSS unterstützen.

A4 mit 18–22 mm Rand, gut lesbarem Fließtext und einem automatisch erzeugten Inhaltsverzeichnis ist ein geeigneter Ausgangspunkt. Seitenumbrüche und Tabellenaufteilung hängen vom jeweiligen Konverter ab; deshalb ist keine feste Seitenzahl vorgegeben.
